# Seer in the Electric Foundation kit

Entry for the Seer Rebrand Contest Part II. The Electric Foundation brand kit is applied to six interfaces.

| Interface | Page |
|---|---|
| Landing page | `index.html` |
| Seer app | `app.html` |
| Futarchy | `futarchy.html` |
| Deep | `deep.html` |
| Opportunity Markets | `opportunity.html` |
| Risk Pricing | `risk.html` |

The site is plain HTML, CSS and JS with no build step. Serve the folder statically or open `index.html`. A simulated wallet and a simulated data layer stand in for the live products, and all data is illustrative.

This is a concept for the contest brief. It does not assume the behaviour of the live products or cover controls outside the brief, such as bookmarking markets.

Design rationale and every departure from the brand kit: [RATIONALE.md](RATIONALE.md).
